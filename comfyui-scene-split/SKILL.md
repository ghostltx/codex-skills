# ComfyUI 场景拆分

将用户提供的场景图拆成可在 ComfyUI 中重新合成的素材。每张源图交付一段英文全场景提示词、一张白底人物图（仅当检测到人物时）和一张清理背景图。

## 输入与边界

- 只处理当前请求中用户提供或明确指定的图片。不要改动原图；所有输出均为新文件。
- 使用内置 `image_gen` 的编辑能力，不使用 API、CLI 或第三方图像服务。若内置编辑不可用或连续失败，说明限制并停止，不切换实现方式。
- 本 Skill 提取人物、清理背景，并描述桌椅以便用户另行渲染；不要生成桌椅成品，也不要把桌椅合成回图中。
- 如果编辑目标仅有本地路径，先用 `view_image` 检查，让它成为可编辑的会话图片。

## 每张图片的工作流

1. 先完整审图，记录原始宽高比、镜头高度与方向、透视、光线、整体风格、所有人物数量和相对位置，以及每张桌子/椅子的材质、颜色、结构、尺寸感和摆放关系。辨认所有可读文字、Logo、招牌和水印。
2. 判断是否存在人类人物（包括完整、局部、远景或镜中可见的人）。多个人物必须作为一个整体保留，不能拆成每人单独文件。没有人物时，明确标记“未检测到人物”，跳过人物白底图，但仍交付提示词与背景图。
3. 写一段可直接复制到 ComfyUI 的英文提示词。它必须是一个连贯段落，按画面整体、镜头/构图/透视、环境、光线与色彩、人物及其动作和位置、桌椅的外观与布局依次描述。只描述源图中真实可见的内容，不虚构家具或人物细节；不要写文字、Logo 或水印。
4. 有人物时，单独发起一次 `image_gen` 编辑生成白底人物图：
   - 完整继承原图宽高比、人物数量、身份特征、服装、发型、表情、动作、相对位置、画面位置、镜头角度和透视；不得裁切或重构画面。
   - 删除所有非人物元素，包括场景、桌子、椅子、道具、文字、Logo、招牌和水印。
   - 用纯白 `#FFFFFF` 背景替换，并保持人物轮廓清晰，不引入额外人物、物体、文字或环境。
5. 另行发起一次 `image_gen` 编辑生成清理背景图：
   - 完整继承原图宽高比、镜头、构图、透视、光线、色彩和未移除的环境。
   - 移除全部人物、桌子与椅子，并自然延展周边纹理、地面、墙面、光影或远景以补全空缺。
   - 清除所有文字、Logo、招牌和水印，且不添加任何新文字或品牌标识。
6. 检查每个结果：画幅比例必须与原图一致；白底图的人数与动作必须正确；背景图不得残留人物、桌椅、可读文本或标识；补全区域不得有明显重复、错位或透视破坏。某项不达标时，只对该资产进行定向编辑重试，最多两次。仍未达标则如实说明具体限制，不以未验证的图片充数。

## 保存与交付

- 在用户桌面创建以源图片文件名（不含扩展名）命名的文件夹，例如源图 `photo.png` 使用 `Desktop/photo/`。从内置工具的默认产出中复制最终选定文件至此目录；不得覆盖既有文件。
- 在同一文件夹保存提示词文本：`<source>-comfyui-scene-prompt.txt`。文本内容只包含该图唯一的一段英文 ComfyUI 提示词。
- 使用源文件名作为图片前缀；文件名不可用时使用 `scene-01`、`scene-02` 等稳定序号。推荐命名：`<source>-person-white-v1.png` 与 `<source>-background-clean-v1.png`；若已有同名文件，创建新的递增版本号，不覆盖旧文件。
- 最终回复按每张源图列出：
  - `ComfyUI Scene Prompt`：该图唯一的一段英文提示词；
  - `Person White Background`：仅有人物时给出保存路径/链接；
  - `Clean Background`：给出保存路径/链接；
  - 简短校验结论，并在无人图时明确说明未生成白底人物图。
