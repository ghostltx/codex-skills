# 修改时间

按 Xelias 的文件名规则修改一张或多张截图左上角时间。用中文回复，开头带贴合语境的 emoji。准确对应和可核验优先；图片数量不设固定上限。

## 解析目标时间

1. 对每张图片分别读取不含扩展名的文件名。
2. 文件名含“改”时，只检查最后一个“改”之后的末尾文本；否则检查整个文件名末尾。
3. 末尾必须匹配 `^(\d{1,2})\.(\d{2})$`。不要从文件名中间猜时间。
4. 不匹配时跳过该图并提示：`文件名末尾未找到需要修改的时间。请把目标时间写在文件名末尾，例如“改8.54”或“8.54”。`
5. 校验小时为 `0–23`、分钟为 `00–59`。超出范围时跳过该图并说明解析到的时间无效，不要自行修正。
6. 输出时间为 `HH:MM`，小时补足两位，例如 `8.54` → `08:54`、`18.05` → `18:05`。

## 建立映射与拼版

- 保持用户提供的输入顺序。为每张有效图片记录源路径、目标时间、原图尺寸与比例、格式、时间区域坐标与尺寸、拼版组号和单元格位置。图片较多时将清单保存在任务工作目录。
- 逐图检查左上角状态栏，确认时间字形边界、字高、字重、颜色、基线和相邻图标。提取包含时间及少量局部背景的区域，避免纳入容易误改的图标或其他文字。
- 默认把所有清晰可辨的时间区域按输入顺序排成单张时间拼版，并用一次 ImageGen 调用编辑整张拼版。5 张时优先纵向一列。数量增加或时间会变得太小时，按行优先网格或拆组；每格必须清晰且与映射清单一一对应，不能为减少调用次数牺牲准确性。
- 生成前检查拼版顺序和映射；不烧录可能被模型复制或改写的编号。提示词按顺序列出每个格子的“原时间 → 目标时间”，要求仅更改数字和冒号，保持字号、字重、颜色、基线与格子布局。按 2K 级清晰度提出生成要求，并选择适合拼版的竖横比例。

## ImageGen 默认生成

- 默认使用内置 `image_gen` 工具编辑拼版；不要使用 RH100，也无需按 20 秒轮询。每组提交后等待工具返回生成结果。
- 拼版为本地编辑目标时，先用 `view_image` 查看拼版，再将该拼版作为参考图交给 `image_gen`。提示词必须逐项写明目标时间、输入顺序，以及“只改时间文字；保留各格位置、底色和原文字体观感；不增删内容，不改变画布构图”。
- ImageGen 返回文件默认位于 `$CODEX_HOME/generated_images/...`。记录实际生成路径，不假设工具支持直接输出到源文件目录。
- ImageGen 可能更改拼版尺寸、比例、背景或字体。生成后先按清单逐格放大检查字符和顺序，再按实际生成画布的比例和每格相对位置定位新时间。若字符、对应关系或区域无法可靠确认，不要猜测贴回；对失败组可针对性重做一次，仍不通过则停止交付该组。
- 提取字形蒙版时，从文字紧邻区域估算该单元格的实际底色；不能把拼版画布的外围白色当作文字底色。前景字色与底色分开估算，避免浅灰背景被误识别成笔画或混入新字形。

## 本地贴回与保存

- 只从通过检查的 ImageGen 结果提取时间字形区域，将字形蒙版映射回对应原图。不得把拼版或整张生成图当作成品。
- 在原图上清除旧时间后，使用原时间的颜色、字高、位置、基线及尽量接近的字重呈现新字形。保留相邻图标及其他内容；图像尺寸变化时先按原图比例映射坐标，再在本地处理，保证成品尺寸和比例与原图一致。
- 默认将成品保存在源图相同目录，文件名在扩展名前追加“修改后”，例如 `照片.jpg` → `照片修改后.jpg`。不覆盖原图；生成拼版、中间图和检查图存放在任务工作目录。每张输入只交付一个最终文件。
- 若 ImageGen 字形无法与原图匹配到可接受程度，或贴回后出现残影、底色块、重叠、错贴，不交付该图；修正局部处理或重做未通过组后重新核验。

## 两阶段验收

1. **生成图验收：** 按映射清单逐格放大核对目标时间的每个字符、输入顺序、单元格对应关系、字形和是否有额外改动。
2. **贴回图验收：** 逐张放大核对目标时间、字重、颜色、字高、基线、位置和对应源文件；特别比较时间周围及被覆盖区域的底色和明暗，检查是否出现色块、背景偏色、接缝、残影或光晕。背景不匹配时先修复，不得交付。确认画布尺寸与原图一致，并比较编辑区域外的内容。PNG 应确认时间区域外像素未变；JPEG 允许重新编码造成的轻微压缩差异。
3. 最终列出通过的成品与跳过/失败项，成品链接指向源图目录的“修改后”副本。不得把未核验结果称作完成。
